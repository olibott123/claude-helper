Privacy policy

Last updated: 13 October 2026

Who uses it

Claude helper is a personal tool used only by its developer, with the developer's own Google account. It is not offered to anyone else.

What it accesses

With the developer's permission, it reads and changes events on the developer's own Google Calendar and reads and edits the developer's own Google Drive files (Docs and Sheets).

How the data is used

The data is only used to do what the developer asks, such as showing their schedule, adding an event or updating a document. It is processed on the developer's own computer. It is not sold, shared with third parties, or used for advertising.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

The sign-in token is stored only on the developer's own computer. No data is stored on any server run for this tool.

Removing access

Access can be removed at any time at myaccount.google.com/connections.
